# Full-Stack User Management

A full-stack user management application with Next.js frontend and Node.js/Express backend.

## Project Structure

```text
.
├── backend/            # Express / Node.js API server
│   ├── controller/
│   ├── routes/
│   └── app.js
├── frontend/my-app/    # Next.js Frontend Application
│   ├── src/
│   └── package.json
└── .gitignore
```

## Getting Started

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend/my-app
npm install
npm run dev
```
